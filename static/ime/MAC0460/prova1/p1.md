# Regressao Linear
- Prever Valores Continuos a partir da entrada
- Modelo tenta encontrar os pesos que minizem o erro quadratico medio (MSE) entre o valor estimado e o valor real
- O modelo pode ser resolvido analiticamente pela equação normal (Algebra Linear) ou de forma iterativa através do Gradiente Descendente, o Gradiente atualiza os pesos na direção oposta à derivada da função de perda, podendo ser processado ao processar todos os exemplos (batch) ou um a um (estocastico). 
- A taxa de aprendizado controla o tamanho dos passos nessa otimização
- Avaliação normalmente pode ser avaliado pelo coeficiente de determinação (R^2)

# Classificacao Binaria e Probabilistica
- Preve Valores discretos a partir da entrada
- Modelagem Probabilistica: Utilizamos probabilidades a priori e verossimilhança para estimar a probabilidade de cada classe. Pode-se assumir, por exempo, que os dados seguem distribuições gaussianas para definir a fronteira de decisão.

# Regressao Logistica
- Algoritmo discriminativo focado em aprender uma fronteira de decisão linear para problemas de classificação binária
- Utiliza a função sigmoide (logistica) para transformar a saida linear em uma probabilidade entre 0 e 1
- A função de perda é a entropia cruzada. Essa função é derivada da Maximização da Verossimilhança, penalizando pesadamente o modelo quando ele prevê a classe errada com alta confiança.

# Avaliação de Modelos de Classificação
- Pode se usar uma matriz de confusão para ver o desempenho do modelo em diferentes classes, que conta os verdadeiros positivos, falsos positivos, verdadeiros negativos e falsos negativos.
- A partir da matriz de confusão, pode-se calcular métricas como Accuracy (TP+TN/Total), Precision (TP/TP+FP), Recall (TP/TP+FN) e F1-Score (2*Precision*Recall/(Precision+Recall)). O ajuste do limiar depende do contexto do problema, por exemplo, um sistema médico deve priorizar o Recall para minimizar falsos negativos.

# Classificação Multiclasse e Modelos Não Lineares
- Para problemas com mais de duas classes, tecnicas como o One-Versus-All (OVA) ou One-Versus-One (OVO) podem ser utilizadas.
- Outra abordagem é a RL Multinomial que substitui a função sigmoide pela função softmax para generalizar para múltiplas classes. Para a avaliação multiclasse, aplica-se o conceito de micro ou macro average para calcular as métricas de forma agregada.
- O Perceptron é um modelo linear que pode ser extendido para problemas não lineares através de camadas adicionais, formando redes neurais. Ele aprende pesos através do Gradiente Descendente para minimizar uma função de perda, podendo ser treinado de forma batch ou estocástica. Porém falha perante dados não linearmente separáveis.
